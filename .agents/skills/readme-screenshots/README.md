# README screenshot workflow

Run the app locally with `npm run dev`, then run `npm run screenshots -- http://127.0.0.1:3000`. This captures one four-model screenshot at `docs/screenshots/comparison.png` with an isolated browser session. The fixture is in `scripts/readme-catalog.json` and uses real model names, illustrative scores and costs, and OpenRouter context sizes; it never uses an Artificial Analysis key or live API data. Keep the README caption clear that the chart values are estimates.
